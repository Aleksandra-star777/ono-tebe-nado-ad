# Оно тебе надо

Одностраничный сайт аукциона вещей, в которые никто не верил. На странице представлены необычные лоты из мира кино, литературы и искусства, а также информация об аукционе.

Проект посвящён вёрстке интерфейса на HTML и CSS.

## Технологии

- **HTML5** — семантическая разметка страницы.
- **CSS3** — оформление, Flexbox и Grid.
- **БЭМ** — именование основных CSS-классов.
- **Локальные шрифты** Raleway в форматах WOFF и WOFF2.
- **SVG-логотипы и иконки**, изображения в формате JPEG.

## Содержание страницы

- Шапка с навигацией, логотипом и контактами.
- Обложка с названием проекта и кнопкой «Сделать ставку».
- Раздел «Лоты» с тремя карточками.
- Раздел «Об аукционе».
- Подвал с контактами, навигацией и иконками социальных сетей.

Навигация позволяет переходить к разделам страницы по якорным ссылкам.

## Особенности реализации

- Фиксированная ширина страницы — 1100 px.
- Расположение элементов с помощью Flexbox и Grid.
- Фоновые изображения с затемняющим слоем.
- Подключение шрифтов через `@font-face`.

В текущей версии реализована статическая вёрстка. Обработка ставок отсутствует, а часть ссылок использует заглушку `#`. Адаптация для мобильных экранов не реализована.
